# mutadarrib

### استبيان رأي الطلاب حول نظام إلكتروني لإدارة التدريب

عزيزي الطالب /عزيزتي الطالبـة،
يهدف هذا الاستبيان إلى التعرف على آرائك واحتياجاتك حول منصة إلكترونية لإدارة التدريب المهني وامتحان المزاولة، بحيث تساعد الطالب/الخريج على:
  التسجيل كمتدرب.  
التقديم على فرص التدريب لدى المزاولين/المكاتب/المؤسسات/الشركات.
متابعة حالة طلب التدريب واستلام إشعارات القبول أو الرفض أو إكمال التدريب.
جميع الإجابات سرّية وتُستخدم لأغراض بحثية/أكاديمية فقط.

شكرًا لمشاركتك.

 ### أي من هذه الميزات تعتبرها "الأهم" بالنسبة لك في نظام إلكتروني لإدارة التدريب؟  
تقديم طلبات التدريب إلكترونياً /
معرفة حالة الطلب (قيد المراجعة / مقبول / مرفوض)/

توثيق انتهاء التدريب واعتماده من الجهة المختصة/
